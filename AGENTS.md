# Instructions de travail pour les agents

Avant de modifier le projet, lire :

1. [docs/vision.md](docs/vision.md) ;
2. [docs/engineering-work-method.md](docs/engineering-work-method.md) ;
3. la procédure adaptée :
   - [docs/dependency-upgrade-workflow.md](docs/dependency-upgrade-workflow.md) ;
   - [docs/security-quality-triage.md](docs/security-quality-triage.md) ;
   - [docs/upstream-contribution-policy.md](docs/upstream-contribution-policy.md).

Pour toute issue ou PR GitHub du fork, appliquer aussi les conventions de
[docs/github-labels.md](docs/github-labels.md).

Pour les sessions à froid liées au fork MCP CoCo3, lire aussi :

- [docs/mcp-cold-start.md](docs/mcp-cold-start.md) ;
- [docs/mcp-local-smoke-test.md](docs/mcp-local-smoke-test.md).

Garder les changements petits, vérifiables et proportionnés au risque. Ne pas
dupliquer les règles : ces documents constituent la source de vérité partagée
par Copilot, Claude Code, Cursor et les autres agents.
