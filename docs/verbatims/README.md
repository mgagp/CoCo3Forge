# Verbatims

Objectif: conserver des extraits courts qui capturent l’intention, le cadrage et les signaux faibles.

## Bonnes pratiques

- Favoriser des extraits ciblés (pas de dump massif).
- Tagger par thème (ex: `disk`, `keyboard`, `reset`, `display`, `agentic`, `risk`).
- Toujours ajouter une phrase “valeur documentaire”.

## Index

- Ajouter un fichier par session si pertinent, ex:
  - `2026-11-24-kickoff.md`
